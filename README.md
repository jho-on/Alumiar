# Alumiar

Alumiar is an Android application designed to help users build consistent daily routines through a visual calendar. Its goal is to encourage habit formation by providing a simple and intuitive representation of long-term progress.

The application works entirely offline, storing all user data locally on the device.

## Inspiration

Alumiar was inspired by [The Every Day Calendar](https://yetch.studio/products/every-day-goal-calendar), created by Simone Giertz. The application adapts the idea of visually representing habit consistency into a mobile experience while preserving its simplicity and focus on habit building.

## Technologies

* React Native
* TypeScript
* SQLite
* Expo Notifications
